# 手机上用这套配置 —— 说明

配置原件：`FlClash-移动端配置.yaml`（53 节点 / 22 策略组 / 140 规则，已通过真实 mihomo 内核严格校验 `test is successful`）

## 先回答：能，但 iPhone 和安卓走法完全不同

| 手机         | 能不能直接用这份文件             | 用什么客户端                                      |
| ---------- | ---------------------- | ------------------------------------------- |
| **安卓**     | ✅ **可以，原样导入**          | FlClash 安卓版（同一家的，配置格式 100% 一致）              |
| **iPhone** | ❌ **FlClash 没有 iOS 版** | 换成 Stash / Karing（都是 App Store 上的，能直接吃这份文件） |

FlClash 官方只发布 **Windows / macOS / Linux / Android** 四个平台，**没有 iOS**。所以你 iPhone 上要装"另一家的客户端"，但配置本身是通用的（mihomo/Clash 标准格式），照样能读。

## 一、安卓：直接用（5 步）

1. 去官方仓库下 APK：`https://github.com/chen08209/FlClash/releases`  
   选文件名带 **`android-arm64-v8a.apk`** 的那个（现在手机基本都是这个）。
2. 把 `FlClash-移动端配置.yaml` 传到手机（微信文件传输助手 / 数据线都行）。
3. 打开 App → 底部「**配置**」→ 右上角 `+` →「**从文件导入**」→ 选中那个 yaml。
4. 回到首页，打开「**虚拟网卡 / TUN**」开关，授权 VPN。
5. 底部「代理」页，把这几个组点一下确认：
   - 🎯 Google → 选 `🇸🇬 新加坡优选` 或 `🇯🇵 日本优选`
   - ✈️ Telegram → 同上
   - 🤖 AI → 选 `🇺🇸 美国优选`
   - 🚀 节点选择 → `♻️ 自动选择`

**安卓必做的一个设置**：系统设置 → 电池 → 找到 FlClash → 改成「**无限制 / 不优化**」。  
否则锁屏几分钟后 App 被系统杀掉，网就断了——这是安卓上最常见的"用着用着就断了"的原因，跟配置无关。

## 三、这份文件的一个硬伤（重要）

`FlClash-移动端配置.yaml` 里的节点是 **2026-10-15 的静态快照**——服务器地址和 UUID 都写死在文件里。

- 机场**换 UUID 或换 IP** 之后，这份文件里的节点就全废了，手机端会表现为"全部连不上"。
- 电脑上你可以重新导出，但手机不方便。

**长期方案**：把这份配置改成**订阅版**——节点部分换成订阅链接自动拉取，规则和策略组保持这套优化不变，这样永不过期、机场更新自动跟上。

## 四、手机端和电脑端的差异（提前知道，别以为是坏了）

| 项目          | 说明                                                                               |
| ----------- | -------------------------------------------------------------------------------- |
| 延迟数字        | 手机上测通常比电脑**低**（手机到机场入口的链路常更好），别拿两边数字直接比                                          |
| vless「高速」节点 | 这批节点**基本是坏的**（电脑上实测 33 个只有极少数能用，速度 0.2MB/s 级别）→ 手机上也一样，**别选，只用 Hysteria2「专线」系列** |
| 「剩余流量/套餐到期」 | 已经帮你剔掉了，不会出现在列表里                                                                 |
| 苹果服务        | App Store / iCloud / 系统更新走直连规则，**手机上装 App 也会变快**                                 |
